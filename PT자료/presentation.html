02

PROTOTYPE · DASHBOARD

어떤 플랫폼 인가요?

금형조립, 사출, 기계가공, 제조 실습 등 실제 산업 현장에서 촬영된 작업자의 작업 영상 및 사진 데이터를 입력하면, 해당 데이터를 AI로 분석하여 작업자의 숙련도를 예측한 다음 결과를 리포팅 해주는 플랫폼 입니다.

플랫폼 프로토타입 바로가기 ↗
주요 기능이 무엇인가요 1. 특정 작업자 인원의 영상 데이터를 조회하고 해당 영상을 가공, 분석허는 화면을 제공해주는데이터 가공과 분석이 통합된 플랫폼
2. 가공된 데이터를 시스템에 저장하면, 해당 데이터 전처리를 통해오픈소스 AI로 숙련도 분석을 한 뒤 결과를 리포팅해주는 플랫폼

  • 최근 분석된 작업자 목록, AI로 분석한 최근 분석결과 조회, 평가자가 분석한 평가 결과 조회

04

PLATFORM PROCESS · END TO END

플랫폼 기능 프로세스

1. 시스템 관리자가 보유한 작업자·직종별 현장 영상을 업로드 합니다.


2. 작업자의 작업 영상은 시스템 내부에 저장되며, 이후 직접 시스템에서 라벨링하거나, 라벨 데이터(JSON 파일 등)를 업로드합니다.


3. AI가 작업/업로드 된 라벨 데이터를 통해 작업 자세·도구 사용·공정 구간·이상행동을 분석합니다.


4. 분석 결과는 평가기준과 결합해 숙련도 점수·등급으로 산출됩니다.


5. 평가 결과는 이후 보고서 형태로 대시보드에 노출되고 PDF 출력 기능이 제공되어야 합니다.
