# UR Connection 모션그래픽 HTML PT

`index.html`을 Chrome/Edge에서 열면 바로 발표할 수 있습니다.

- 다음/이전: `→`, `←`, `Space`, 마우스 휠, 화면 스와이프
- 전체화면: `F` 또는 하단 전체화면 버튼
- 처음/끝: `Home`, `End`
- PDF 저장: 브라우저 인쇄(`Ctrl+P`) → PDF 저장

## 구성

1. 비전 — 보이는 작업을 신뢰 가능한 역량으로
2. 문제 — 전문가 의존, 평가 지연, 기준 편차
3. 보유 데이터 — 작업 영상·결과물 사진
4. AI 분석 파이프라인
5. 설명 가능한 숙련도 점수
6. 영상 시점과 연결된 평가 근거
7. AI + 전문가 승인
8. 작업자·경력·체류/고용 절차 관리
9. 기업용 포트폴리오·매칭 추천
10. 요구 시스템과 비기능 요구사항
11. 개발 로드맵
12. 결론

## 근거 자료

동일 저장소의 `docs/` 문서, `web/src/` 프로토타입, `docs/화면설계서/images/`, `web/public/evidence/`를 분석해 구성했습니다. 현재 저장소 상태는 목데이터 기반 프론트 프로토타입이며, 실 AI·백엔드 연동은 후속 단계입니다.
