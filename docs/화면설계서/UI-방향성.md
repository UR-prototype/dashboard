# UR Connection 대시보드 UI 방향성

> 기준 자료: 수요기업(UR 커넥션) 제공 「대시보드 및 동영상」 스크린샷 8장  
> 목적: 해외인력 기량 검증·매칭 플랫폼 관리자 화면의 시각/구조 가이드

---

## 1. 제품 포지션

- **제품명:** UR Connection (URConnection)
- **유형:** B2B 관리자 대시보드 (글로벌 인력 매칭 / 아웃소싱)
- **핵심 가치:** 해외인력의 **기량 검증 미디어(영상·사진)** 와 **채용·비자 파이프라인 현황** 을 한 화면에서 조회·관리
- **주요 사용자:** 운영 관리자, 에이전시/파견 담당, 수요기업 담당자

---

## 2. 레이아웃 원칙

| 영역 | 역할 | 규칙 |
|------|------|------|
| **좌측 글로벌 사이드바** | 앱 전역 메뉴 | 고정 폭, 스크롤 가능, 하단에 Logout 고정 |
| **상단/본문 헤더** | 현재 컨텍스트 | 목록: 페이지 타이틀+설명 / 상세: < 이름 백 네비 |
| **본문** | 데이터·미디어 | 흰 카드 + 여백, 테이블 또는 미디어 뷰어 |
| **상세 서브내비** | 인력 프로필 섹션 | 본문 좌측 세로 탭 (Personal Information ~ Pre Test) |

**3단 정보 구조**

`
[글로벌 사이드바] → [목록/상세] → [상세 서브 섹션]
`

목록(해외인력)과 상세(인력 프로필)를 분리하고, 상세 안에서는 세로 탭으로 정보 유형을 전환한다.

---

## 3. 비주얼 톤

| 항목 | 방향 |
|------|------|
| 테마 | **라이트 모드** (화이트 / 라이트 그레이 배경) |
| 분위기 | 클린 SaaS, 업무용, 과장된 장식·글로우 없음 |
| 타이포 | 산세리프, 데이터 가독성 우선 |
| 아이콘 | 얇은 라인 아이콘, 메뉴·섹션 옆 일관 배치 |
| 카드 | 흰 배경, 얇은 보더, 약한 라운드, 과도한 그림자 지양 |
| 미디어 | 영상·사진은 **본문 중앙의 큰 뷰어/그리드**로 강조 |

### 컬러 역할

| 역할 | 용도 | 참고 |
|------|------|------|
| Primary Blue | 활성 탭, 선택 상태, 브랜드 강조 | 사이드/서브내비 active |
| Neutral Gray | 텍스트, 보더, 비활성 | 본문 기본 |
| Status Yellow | 대기 등 주의 상태 | 테이블 Status |
| Danger Red | Logout, 삭제 | 파괴적 액션만 |
| Success/Info | 승인·배정 등 긍정적 액션 버튼 | 테이블 Actions |

> 구현 시 브랜드 블루는 로고(UR Connection) 톤에 맞추고, 보라/네온/다크 테마는 사용하지 않는다.

## 4. 정보 아키텍처 (IA)

### 4.1 글로벌 메뉴 (사이드바)

- **Total Data:** All information, Applicants
- **Outsourcing:** Companies, Agencies, Workers, Parties, Pre test
- **Office:** Attendance Tracking, Calendar, Recruitment, Jobs
- **기타:** Marketing, Projects, Chat, Settings, Control Panel, Support chat bot
- **Logout** (사이드바 하단, 빨강)

이번 스마트서비스 범위의 **핵심 화면**은 Outsourcing > Workers(해외인력) 및 인력 상세의 **Video and Photos / Pre Test** 이다.

### 4.2 인력 상세 서브 섹션

1. Personal Information  
2. Emergency Contact  
3. Additional Information  
4. University  
5. Language Proficiency  
6. Professional Certificate  
7. Workplace Information  
8. **Video and Photos** ← 기량검증 핵심  
9. Pre Test

## 5. 핵심 화면 패턴

### A. 목록형 — 해외인력 등록 현황 및 관리

1. **KPI 카드 행** — 파이프라인 단계별 인원 수 (전체 → 기술시험 → 인터뷰 → … → 관리단계)
2. **검색** — 넓은 단일 검색바
3. **필터 드롭다운 행** — 스킬 / Party / Agency / Company / Skill category / Exam status
4. **데이터 테이블** — 프로필·스킬·성명·소속·나이·국적·상태·시험·회사배정·액션

**KPI 예시 단계:** 전체 근로자 → 기술 시험 → 인터뷰 → 사전 신청 → 비자 진행 → 비자 발급 → 입국 완료 → 관리 단계

### B. 상세형 — 인력 프로필 + 미디어

- 헤더: < {성명}
- 좌: 서브내비 / 우: 섹션 콘텐츠
- **Video and Photos** 내부 콘텐츠 유형:
  - 작업 현장·부품 **사진 그리드**
  - **Interview Video** (인터뷰)
  - **Experience Video** (실무 경험)
  - **Skills Verification Video** (기량 검증)
  - **Other Videos / Other Photos**

미디어는 채용 판단의 근거이므로, 텍스트 폼보다 **큰 플레이어·그리드**가 주인공이다.

## 6. 인터랙션 가이드

| 요소 | 동작 |
|------|------|
| KPI 카드 | 클릭 시 해당 단계 필터 연동 권장 |
| 테이블 행 / 자세히보기 | 인력 상세로 이동 |
| Exam / Company 셀 | 인라인 드롭다운으로 즉시 배정 |
| Actions | 이관 / 승인 / 삭제 (아이콘 버튼) |
| 서브내비 | 클릭 시 우측 콘텐츠만 교체 (전체 리로드 지양) |
| 비디오 | 표준 컨트롤(재생·시크·음량·전체화면) |

---

## 7. 구현 시 우선순위 (권장)

1. **공통 셸** — 사이드바 + 헤더 + 로그아웃  
2. **해외인력 목록** — KPI + 검색/필터 + 테이블  
3. **인력 상세 셸** — 서브내비 + 섹션 라우팅  
4. **Video and Photos** — 사진 그리드 + 영상 플레이어  
5. 나머지 프로필 섹션·Pre Test  

---

## 8. 하지 않을 것 (안티패턴)

- 다크 모드 기본 적용
- 히어로·마케팅형 랜딩을 관리자 UI에 섞기
- KPI/테이블을 카드 과다 장식으로 가리기
- 기량검증 영상을 썸네일만 두고 상세 재생 경로를 없애기
- 사이드바와 상세 서브내비를 한 메뉴로 뭉개기 (계층이 핵심)
