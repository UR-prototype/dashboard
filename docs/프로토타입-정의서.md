## 6. 점수 산정

```text
Skill Score = 0.30×Speed + 0.25×Stability + 0.20×Repetition + 0.25×Accuracy
등급: 0–64 초급 · 65–84 중급 · 85–100 고급
```

---

## 7. 결과 활용 — 매칭 추천 (의사결정)

점수만 끝내지 않고 **채용/배치 액션**으로 연결한다.

| 숙련도 | 매칭 가능 | 추천 예시 |
|--------|-----------|-----------|
| 고급 (85+) | 즉시 매칭 | 고정밀 가공 라인, 숙련 필수 현장 |
| 중급 (65–84) | 조건부 매칭 | 금형조립 보조→주작업, 교육 병행 |
| 초급 (&lt;65) | 교육 후 재평가 | 단순 공정·OJT 우선 |

결과 객체에 `matching` 필드를 둔다.

```json
{
  "skill_score": 78,
  "matching": {
    "eligible": true,
    "recommended_job": "금형조립 (주작업 가능)",
    "recommended_sites": ["자동차부품 A라인", "금형셀 B"],
    "reason": "중급 · 반복성 양호 · Idle 보완 시 즉시 투입 가능"
  }
}
```

## 9. 모델 로드맵

```text
Pose Estimation (MediaPipe)
        ↓
Feature Engineering
        ↓
Rule-based Score Engine   ← MVP (현재)
        ↓
향후 ML Regression / Classifier  (라벨·수기점수 학습)
```

MVP는 **설명 가능한 규칙 기반**을 유지하고, 데이터 축적 후 ML로 고도화.

## 10. 신뢰도 · 상태 · Explain

- Confidence: `ai_confidence`, `pose_tracking_quality`, `detection_coverage`
- 감점 Explain: Idle / Hand Travel / Tool Switch + `t` 타임라인 연동
- 결과물 판정: 기준 샘플 대조 → 정확도 반영

### 시연 UX (P0 인터랙션)

| 요소 | 목적 |
|------|------|
| AI Explain Card | 10초 내 점수·강점·개선·매칭 이해 |
| Pipeline Progress (단계별 바) | “AI가 분석 중” 체감 |
| Pose Overlay 3모드 | MediaPipe 실분석 인상 |
| Timeline Scrubber | 감점 시각 ↔ 장면 연동 |
