# 시스템 아키텍처

> 문서를 처음 보는 사람이 **한 장으로 전체 구조를 파악**하기 위한 개요.

## 1. 전체 구성도

```text
┌─────────────┐
│   Browser   │  기업담당자 / 평가자 / 관리자
└──────┬──────┘
       │
┌──────▼──────┐
│   Next.js   │  Dashboard · Worker · Analysis · Report UI
│  (Frontend) │
└──────┬──────┘
       │ REST /api/v1
┌──────▼──────┐
│   FastAPI   │  Auth · CRUD · Job 제어 · Report
│  (Backend)  │
└──────┬──────┘
       │ enqueue
┌──────▼──────────┐
│ Analysis Queue  │  uploaded → … → completed / failed
└──────┬──────────┘
       │
┌──────▼──────────┐
│ MediaPipe Pose  │  Pose Estimation (관절 시계열)
└──────┬──────────┘
       │
┌──────▼──────────┐
│ Feature Engine  │  idle, travel, cycle, tool_switch …
└──────┬──────────┘
       │
┌──────▼──────────┐
│  Score Engine   │  MVP: Rule-based 가중치
│                 │  향후: ML Regression
└──────┬──────────┘
       │
┌──────▼──────┐     ┌────────────┐
│   MySQL     │────▶│  Dashboard │  결과·Trend·매칭·운영
│  + Files    │     └────────────┘
└─────────────┘
```

## 2. 계층 역할

| 계층 | 역할 |
|------|------|
| Browser / Next.js | 의사결정 UI — 점수·Explain·매칭·리포트 |
| FastAPI | API 게이트웨이, 권한, 잡 생성/재실행 |
| Analysis Queue | 비동기 파이프라인 상태 머신 |
| MediaPipe | Pose Estimation |
| Feature Engine | Joint → 정량 Feature |
| Score Engine | Feature → Skill Score + 감점 |
| MySQL + Storage | Workers, Videos, Results, Pose/JSON |

## 3. 데이터 흐름 (의사결정까지)

```text
영상 업로드
  → AI 분석 (Pose→Feature→Score)
  → 검토·승인
  → 매칭 추천 (직무·현장)
  → PDF 평가서
  → 채용/배치 의사결정
```
